# Email Content Generation Rules

This document contains rules for generating three email types: Direct, Indirect (Faulty Belief), and Value emails.

## CRITICAL FORMATTING RULES (ALL EMAIL TYPES)

1. **One sentence per line** (absolutely no exceptions)
2. **No double line breaks** between sentences within paragraphs
3. **Single line break** between related sentences
4. **Double line break** only between major sections
5. **Backticks around CTA variables**: `{{cta_link}}` or `{{app_cta}}`

---

## TYPE 1: DIRECT EMAIL

### Purpose
Short, focused emails that drive immediate action from warm/engaged subscribers.

### Structure
**Length**: 100-200 words

1. **Direct Hook** (1-2 sentences)
2. **Value/Reason** (2-3 sentences)
3. **Clear CTA** (1-2 sentences)
4. **Sign-off**

### Subject Line Patterns

**Question Pattern** (most effective):
- "Ready to [specific outcome]?" (20-30 chars)
- "[Specific result] in [timeframe]?" (25-35 chars)

**Urgency Pattern**:
- "Last call for [specific offer]" (25-35 chars)
- "[Number] spots left for [outcome]" (30-40 chars)

**Personal Pattern**:
- "Quick question for you" (22 chars)
- "This is for you if..." (19 chars)

### Voice
- Direct and confident, not pushy
- Assumption of interest
- Specific outcomes with numbers
- Premium positioning
- One obvious action

## TYPE 2: INDIRECT EMAIL (Faulty Belief Framework)

### Purpose
Educational emails that challenge conventional wisdom while driving qualified conversions. Highest-ROI emails when done correctly.

### Structure
**Length**: 400-600 words

1. **Conversational Subject Line** (5-9 words, story-driven)
2. **Hook** - Challenge belief or share surprising insight (1-2 sentences)
3. **Story/Case Study** - Specific client example (3-4 sentences)
4. **Faulty Belief** - Why common approach fails (2-3 sentences)
5. **Truth** - What actually works instead (2-3 sentences)
6. **Proof** - Additional evidence/results (1-2 sentences)
7. **Bridge** - Connect to reader's situation (1-2 sentences)
8. **CTA** - Single clear call-to-action (1-2 sentences)
9. **Sign-off**

### Case Study Structure

Must include:
- **Client situation**: What they came in believing/doing
- **Specific problem**: What wasn't working (with numbers)
- **Solution**: What you/they did instead
- **Results**: Measurable outcomes with timeframe
- **Key insight**: The "aha moment"

**Example Pattern:**
```
[Client name] came to me thinking [faulty belief].
They were [specific struggle] and getting [poor results].
So we [specific change made].
In [timeframe], they [specific measurable outcome].
The breakthrough happened when they realized [key insight].
```

### Faulty Belief Framework

**1. Common Belief Identification:**
```
Most [audience] think [incorrect assumption].
Everyone says you need to [wrong approach].
The conventional wisdom is [faulty belief].
```

**2. Why It's Wrong:**
```
But here's the problem with that approach:
[Specific reason why it fails]
[Additional evidence of failure]
```

**3. What's Actually True:**
```
What actually works is [counter-intuitive truth].
Instead of [old way], you should [new approach].
```

**4. Proof/Evidence:**
```
We've seen this with [number] clients.
[Additional example or data point].
```

### Voice
- Business-first, conversational
- No-bullshit directness
- Founder energy (operators, not academics)
- Start sentences with "So" and "Because" naturally
- Challenge assumptions directly but respectfully

## TYPE 3: VALUE EMAIL

### Purpose
Goodwill-building emails that educate without direct selling. Build authority and trust for future conversions.

### Structure
**Length**: 400-500 words

1. **Personal Credibility Hook** (2-3 sentences)
2. **Problem Recognition** (2-3 sentences)
3. **Value Delivery** (8-12 sentences)
4. **Soft CTA** (1-2 sentences)
5. **Sign-off**

### Subject Line Patterns

**Single Tool Focus** (highest converting):
- "[Specific tool] that [specific outcome]" (30-40 chars)
- "How I [specific result] with ONE [tool]" (30-40 chars)
- "The [tool] workflow that [outcome]" (35-45 chars)

**AVOID** (these fail):
- "[Number] tools for [audience]" (breadth = failure)
- Overview approaches

### Value Delivery Section

**ANTI-BREADTH GUARDRAILS (CRITICAL):**
- ✅ Maximum 2 tools total (1 primary + 1 supporting)
- ✅ Primary tool gets 150+ words (detailed implementation)
- ✅ Minimum 3 tactical steps per tool
- ✅ Interface/screenshot details (describe what user sees)

**Primary Tool Structure (80% of content):**
- Tool Name (with version/pricing if relevant)
- What it does (one sentence)
- Step-by-step setup:
  - Step 1: [Specific action with interface details]
  - Step 2: [Next action with what user sees]
  - Step 3: [Implementation with expected result]
- Troubleshooting: "If [common issue], [specific fix]"
- Your Results: Exact metrics and timeframe
- Why this beats alternatives: Specific comparison

### Voice
- Helpful teacher, not salesy
- Specific over generic
- Personal experience (what you actually use)
- Conversational ("Here's what I've learned...")
- Practical (every tool has a "how to use it")

## Scoring Rubric (Target: 18/25)

### 1. SUBJECT LINE (0-5)
- Specific outcome or curiosity trigger?
- Under 50 chars (mobile preview)?
- Would YOU open this email?

### 2. HOOK QUALITY (0-5)
- First sentence earns the second?
- Specific details, not generic?
- Creates forward momentum?

### 3. VALUE DENSITY (0-5)
- Every paragraph adds new value?
- Concrete examples (not abstract)?
- Feels like insider knowledge?

### 4. PROOF POINTS (0-5)
- Specific numbers (not vague)?
- Real client examples (if applicable)?
- 2+ credibility signals?

### 5. CTA CLARITY (0-5)
- One obvious action?
- Specific, not generic ("Click here")?
- Placed at natural decision point?

## AI Patterns to Avoid

**Auto-fail patterns:**
- Contrast framing: "It's not X, it's Y" / "This isn't about X—it's about Y"
- Rule of Three: "Same X. Same Y. Over Z%."
- Staccato openings (short. punchy. dramatic.)

**Inline questions (FLAG ALL `?` IN BODY):**
- CTA at END → OK
- Rhetorical questions mid-email → FIX
- "The truth?" / "The catch?" / "Sound familiar?" → DELETE

**Forbidden phrases:**
- "Here's the thing:" / "The reality is:" / "At the end of the day"
- "Let's dive deep" / "Let's unpack" / "In today's digital landscape"
- "I wanted to reach out" / "Hope this email finds you well"

**Human Voice Patterns (use these):**
- Contractions: "I'm", "I've", "here're", "that's"
- Informal starters: "So", "And", "But", "Now"
- Direct: Start sentences with verbs
- Hedging: "pretty well", "a bunch of"

## Rich vs Thin Context

**If user provides detailed brief (>200 words):**
- PRESERVE their strategic thinking
- Polish, don't rewrite
- Keep their examples, numbers, voice
- Remove only AI tells

**If user provides topic only (<200 words):**
- Ask: Direct, Indirect, or Value email?
- Follow appropriate type structure
- Build from subject line down

## Universal Email Rules

### Quality Standards
- Lead with value, not ego
- Use active voice
- Include specific examples and data
- Always include clear CTA
- Proofread for clarity and flow

### Formatting (CRITICAL)
- One sentence per line
- No double line breaks within paragraphs
- Single line break between related sentences
- Double line break only between sections

### Ethical Boundaries
- Never fabricate data or testimonials
- Always disclose affiliations
- Respect intellectual property
- Maintain professional standards

## Quality Checklist

Before delivering:
- [ ] Subject line under 50 chars
- [ ] Hook earns the second sentence
- [ ] Zero AI patterns
- [ ] One sentence per line formatting
- [ ] Clear, specific CTA
- [ ] Appropriate length for email type
