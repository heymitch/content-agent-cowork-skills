# LinkedIn Content Generation

Generate thought leadership content optimized for LinkedIn's 2,800 character limit.

## Content Styles

Pick one based on topic:
- **Steps** - Sequential how-to guides
- **Stats** - Data-driven insights
- **Mistakes** - Common pitfalls to avoid
- **Lessons** - Learnings from experience
- **Examples** - Case studies and proof points

## Format Decision

**OUTLINE (50-120 words)** - Use for simple lists, quick tips:
- Hook + line break
- 1-2 sentence setup
- 3-5 bullets (tangible, specific)
- One-line CTA

**LONG-FORM (200-450 words)** - Use for stories, frameworks, depth:
- Hook + MANDATORY line break
- Introduction (200-400 chars)
- 3-5 sections with tangible headers
- Alternate: bullets → paragraph → bullets
- Conclusion with engagement trigger

**Rule:** If you can deliver full value in 3-5 bullets, use OUTLINE.

## Scoring Rubric (Target: 18/25)

### 1. HOOK QUALITY (0-5)
- Proven framework? (question/bold statement/specific stat/story opener)
- Specific details? ("$15K mistake" not "I learned something")
- Ends on cliffhanger? (?, :, ..., mid-sentence)

### 2. AUDIENCE SPECIFICITY (0-5)
- Role specific? ("B2B marketers" not "marketers")
- Stage specific? ("seed-stage founders" not "founders")
- Problem specific? ("stuck at $1M ARR" not "need help")

### 3. HEADER TANGIBILITY (0-5)
- Metrics/outcomes/timeframes? ("Cut sales cycle from 41 to 23 days")
- Skimmable and actionable?
- NO generic phrases ("What I learned", "Key insights")

### 4. NUMERIC PROOF (0-5)
- 2+ concrete numbers? ($15K, 73%, 2,847 emails)
- Specific, not vague? ("97% reduction" not "significant improvement")

### 5. ENGAGEMENT TRIGGER (0-5)
- Specific CTA? ("Which step would move the needle for you?")
- Invites participation? ("Comment 'checklist'", "Share your flow")
- NO passive CTAs ("DM me", "Link in bio", "Follow for more")

## Critical Rules

### Character Limit
**NON-NEGOTIABLE: ≤2,800 characters.** Count before delivering.

### First 200 Characters
Hook + cliffhanger before "See more" button. This is everything.

### Section Structure
| Section | Length |
|---------|--------|
| Hook | ~200 chars |
| Introduction | 300-400 chars |
| Each main section | 300-450 chars max |
| Conclusion | 100-200 chars |

### Alternate Format Pattern
Section 1: Bullets → Section 2: Paragraph → Section 3: Bullets

### Output Format
**Plain text only.** No markdown syntax (**bold**, # headers, [links]).
Direct copy-paste to LinkedIn.

## AI Patterns to Avoid

**Auto-fail patterns:**
- Contrast framing: "It's not X, it's Y" / "This isn't about X—it's about Y"
- Rule of Three: "Same X. Same Y. Over Z%." (sentence fragments, not lists)

**Inline questions (FLAG ALL `?` IN BODY):**
- CTA at END → OK
- Mid-content questions → FIX
- "The other 39?" / "The catch?" / "Sound familiar?" → DELETE

**Forbidden:**
- "Here's the thing:" / "The reality is:" / "At the end of the day"
- "Let's dive deep" / "Let's unpack" / "In today's digital landscape"
- Generic CTAs: "DM me for help" / "Follow for more"
- Hashtags (real LinkedIn pros don't use them)

## Human Voice Patterns

**Use these:**
- Contractions: "I'm", "I've", "here're", "that's"
- Informal starters: "So", "And", "But", "Now"
- Hedging: "pretty well", "a bunch of", "I'm definitely looking to"
- Fragments: "And that's it!", "Boom!"

**Tone:** BBQ conversation, not corporate pitch. Explaining to a colleague, not presenting to a board.

## Rich vs Thin Context

**If user provides detailed outline (>200 words):**
- PRESERVE their strategic thinking
- Polish, don't rewrite
- Keep their language, numbers, anecdotes
- Remove only AI tells

**If user provides topic only (<200 words):**
- Create from scratch
- Follow format decision rules
- Build narrative from hook

## Quality Checklist

Before delivering:
- [ ] Under 2,800 characters
- [ ] First 200 chars = hook + cliffhanger
- [ ] Headers deliver 80% of value on their own
- [ ] Format alternates (bullets/paragraph)
- [ ] Zero AI patterns
- [ ] 2+ specific numbers
- [ ] Active engagement CTA
- [ ] Plain text (no markdown)
