# 10x Content Leverage Framework

This framework helps you extract maximum value from a single piece of content by systematically transforming it across formats and platforms.

## Core Principle

One piece of quality content can generate 10+ derivative pieces without creating from scratch.

## The 10x Transformation Chain

### Level 1: Source Content
Start with ONE high-value piece:
- Long-form article/blog post
- Video/podcast transcript
- Client case study
- Personal experience/lesson
- Book/course notes
- Meeting/presentation notes

### Level 2: Platform Adaptations (3-4 pieces)

**LinkedIn Post**
- Extract the core insight
- Add personal angle or story
- Include specific numbers/results
- End with engagement question

**Twitter/X Thread**
- Break into 5-10 sequential insights
- Each tweet must stand alone AND connect
- First tweet = strongest hook
- Last tweet = CTA

**Email**
- Frame as lesson/story for subscriber
- Add exclusive angle or detail
- Include clear next step

**Short Video Script**
- Hook in first 3 seconds
- One key takeaway
- Visual examples
- Strong CTA

### Level 3: Micro-Content (5-6 pieces)

From each Level 2 piece, extract:

**Quote Graphics**
- Pull single powerful sentences
- Add attribution
- Design for sharing

**Carousel Slides**
- Turn list into visual slides
- 5-10 slides per carousel
- Each slide = one point

**Single Tweets**
- One insight = one tweet
- Can schedule across week

**Stories/Reels**
- Quick-hit version of key points
- 15-30 seconds each

## Application Process

### Step 1: Identify the Core
What's the ONE key insight from your source content?
- Problem it solves
- Counterintuitive truth
- Specific result achieved

### Step 2: Extract Building Blocks
From the source, pull out:
- [ ] 3-5 main points/steps
- [ ] 1-2 stories/examples
- [ ] Key stats or numbers
- [ ] Memorable phrases/quotes
- [ ] The "aha moment"

### Step 3: Transform by Platform

| Source Element | LinkedIn | Twitter | Email | Video |
|---------------|----------|---------|-------|-------|
| Main insight | Lead/hook | First tweet | Opening | Hook |
| Points/steps | Numbered sections | Thread tweets | Body bullets | Visual steps |
| Story/example | Context builder | 1-2 tweets | Case study | B-roll moment |
| Stats/numbers | Proof points | Standalone tweet | Subject line hook | On-screen text |
| Quote | Section header | Quote tweet | Email sign-off | End card |

### Step 4: Adapt the Angle

Same content, different angles:

**Educational Angle**
"How to [achieve result]"

**Story Angle**
"What happened when I [did thing]"

**Mistake Angle**
"The #1 mistake [audience] makes with [topic]"

**Contrarian Angle**
"Why [common belief] is wrong"

**Data Angle**
"[Specific stat] proves [insight]"

## Example: Case Study → 10x Content

**Source**: Client achieved 40% more sales with AI automation

**LinkedIn Post**: "How [Client] increased sales 40% without hiring"
**Twitter Thread**: "I helped a client add $200K in revenue. Here's the 5-step system:"
**Single Tweet**: "40% more sales. Same team size. One AI workflow. Results in 30 days."
**Email**: Faulty Belief - "You don't need more salespeople, you need better systems"
**Video**: "Stop hiring. Start automating. Here's how one client added 40% revenue..."
**Quote Graphic**: "The best sales hack isn't a hack at all—it's removing friction."
**Carousel**: "5 Automations That Added $200K to My Client's Revenue"

## Quality Guardrails

- Each piece must stand alone (don't assume context)
- Adapt format, not just copy/paste
- Maintain consistent brand voice across all
- Each platform version should feel native
- Always include CTA appropriate to platform

## When to Use This Framework

✅ Use when:
- You have a high-performing piece to extend
- You need to fill content calendar efficiently
- You want consistent messaging across platforms
- You're repurposing client results/case studies

❌ Don't use when:
- Source content is weak (amplifies weakness)
- Topic requires platform-specific nuance
- You're just trying to "look busy" with content
