# Twitter/X Content Generation

Generate tweets and threads optimized for Twitter's format.

## Format Decision (CRITICAL)

**SINGLE POST (default)** - 280 chars max:
Ask: "Can I deliver this in 280 characters?" If yes → single.
- **Paragraph**: Single declarative perspective
- **Hot Take**: Bold/controversial statement
- **What/How/Why**: Quick observation → reason

**SHORT THREAD (3-4 tweets)** - Only if needed:
- One main point with 2-3 supporting examples
- Each tweet under 280 chars

**LONG THREAD (5-10 tweets)** - Complex arguments only:
- Setup → Examples → Insight → CTA
- Each tweet advances the argument

**BIAS TOWARD SINGLES.** Most thoughts fit in 280 chars. Threads are for depth, not default.

## Scoring Rubric (Target: 18/25)

### 1. HOOK STRENGTH (0-5)
- Grabs attention immediately?
- Specific with concrete details?
- Creates intrigue?

Score 5: "You have no idea how degenerate and hedonistic things are about to get."
Score 0: "AI is changing everything"

### 2. THREAD FLOW (0-5) [if thread]
- Each tweet builds on previous?
- Logical progression?
- Maintains momentum?

### 3. BREVITY + RATE OF REVELATION (0-5)
- Each tweet under 280 chars?
- Each reveals NEW information?
- Zero fluff?

### 4. PROOF/CREDIBILITY (0-5)
- Concrete examples from user's context?
- ZERO fabricated names, companies, metrics?

### 5. ENGAGEMENT TRIGGER (0-5)
- Ends with question or CTA?
- Invites replies?
- NOT passive ("Follow for more")

## Character Limit

**280 characters per tweet.** Non-negotiable.

## Twitter-Specific Rules

- Thread numbering: 1/, 2/, 3/ format
- NO markdown formatting
- NO hashtags in body (they look spammy)
- 1-2 emoji max per tweet (use sparingly)
- All lowercase is authentic
- Casual, conversational tone

## AI Patterns to Avoid

**Auto-fail:**
- Contrast framing: "It's not X, it's Y"
- Rule of Three: "Same X. Same Y. Over Z%."

**Inline questions (FLAG ALL `?`):**
- CTA at END → OK
- Mid-thread questions → DELETE
- "The catch?" / "Sound familiar?" → DELETE

**Forbidden:**
- "In today's landscape" / "Moreover" / "Furthermore"
- Generic intros: "Here are X ways to..."
- Hashtags

## Human Voice Patterns

**Use these:**
- Contractions: "I'm", "I've", "here're", "that's"
- Starters: "So", "And", "But"
- Hedging: "pretty well", "a bunch of"
- Lowercase: "this is how I would design..."
- Fragments: "Boom.", "That's it."

## Example Formats

**Hot Take (Single):**
```
lock in or you're gonna get cooked.
```

**Listicle (Short Thread):**
```
Nearly all geniuses were:
- privately educated with elite tutors
- introduced to complex topics young
- around adults instead of peers when young
```

**Declarative (Single):**
```
GPT-5 shows we've crossed the point where most people can't tell if one AI model is better than another.

From here, models will be judged on vibe and utility.
```

## Rich vs Thin Context

**If user provides detailed outline (>100 words):**
- PRESERVE their strategic thinking
- Polish, don't rewrite
- Keep their language, numbers, anecdotes
- Remove only AI tells

**If user provides topic only (<100 words):**
- Create from scratch
- Follow format decision rules
- BIAS TOWARD SINGLES unless depth required

## Quality Checklist

Before delivering:
- [ ] Each tweet ≤280 chars
- [ ] Hook grabs attention immediately
- [ ] Zero AI patterns
- [ ] Natural flow (if thread)
- [ ] Engagement trigger at end
- [ ] No hashtags
- [ ] Plain text output
